# Assets Directory

This directory contains demo images, videos, and visual assets for the Speed Breaker Recognition System.

## Contents

### Demo Images
- `demo_image_1.jpg` - Sample speed breaker detection result
- `demo_image_2.jpg` - Detection under different lighting conditions
- `demo_image_3.jpg` - Multiple speed breaker detection
- `original_samples/` - Unprocessed sample images

### Demo Videos
- `demo_video.mp4` - Real-time detection demonstration
- `detection_results.mp4` - Annotated detection output

### Visualization
- `confusion_matrix.png` - Model performance visualization
- `training_curves.png` - Loss and accuracy curves
- `sample_predictions.png` - Grid of sample predictions

## Usage

These assets can be used for:
- Testing the inference pipeline
- Demonstrating model capabilities
- Documentation and presentations
- Benchmarking performance

## Adding New Assets

Place new demo files in this directory with descriptive names:

```bash
# Images
cp your_image.jpg assets/demo_image_4.jpg

# Videos
cp your_video.mp4 assets/demo_video_2.mp4
```
